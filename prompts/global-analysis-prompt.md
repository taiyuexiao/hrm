# AI 全局分析 Prompt 说明文档

## 功能概述

AI 全局分析功能用于对选定周的所有部门周报进行跨部门的综合分析，生成包含完成度评估、偏离度判断、重点工作推进情况和关键结论的全局报告。

## Prompt 结构

### 1. 系统角色设定

```
你是一位数据部门的高级管理顾问，擅长周报全局分析与战略洞察。
```

**作用**：为 AI 设定专业背景和分析视角，确保输出符合管理层需求。

---

### 2. 输出格式要求

要求 AI 严格按照以下 Markdown 格式输出（不添加代码块标记）：

```markdown
# ${selectedWeek} 周报全局分析

## 一、各科室完成度与偏离度

| 科室 | 偏离度 | 核心判断 |
|------|--------|----------|
| [科室名称] | [偏离度等级] | [判断依据] |

## 二、0327→${selectedWeek} 重点工作整体推进

[分析从2026-W12(0327)至今的重点工作推进情况]

## 三、${selectedWeek}「三句话关键结论」

**本周相对本周计划**：[本周实际完成情况与计划的对比]

**0313 以来阶段主线**：[从0313以来的主要工作主线和变化趋势]

**盯盘清单**：[需要重点关注的科室和事项]
```

---

### 3. 分析要求详解

#### 3.1 偏离度评判标准

根据本周实际工作与上周"下周计划"的对比，评判为五档：

| 等级 | 含义 | 判断标准 |
|------|------|----------|
| **绿** | 完全按计划推进，无偏离 | 上周计划的所有事项均已完成，且质量符合预期 |
| **绿黄** | 基本按计划，有轻微偏离 | 大部分计划完成，少数事项有轻微延迟或调整 |
| **黄** | 部分偏离，有未完成项 | 约50%-70%的计划完成，部分重要事项未完成 |
| **黄红** | 明显偏离，多项未完成 | 仅30%-50%的计划完成，多项关键事项延迟 |
| **红** | 严重偏离，大部分未完成 | 少于30%的计划完成，或关键里程碑严重延迟 |

#### 3.2 核心判断要点

- **完成的关键事项**：列出本周实际完成的重要工作
- **未完成/延迟事项**：指出计划中但未完成的事项
- **偏离原因**：简要说明偏离的可能原因（如需求变更、资源不足、依赖阻塞等）
- **风险提示**：标注可能影响后续工作的风险点

#### 3.3 重点工作推进分析

- **识别跨科室主线**：找出多个科室共同推进的重点项目或工作主线
- **时间跨度**：从 2026-W12 (0327) 至当前周的整体推进情况
- **进展评估**：每个重点工作一段，格式为 `**工作名称**：进展描述`
- **趋势分析**：指出工作推进的趋势（加速/稳定/放缓）

#### 3.4 三句话关键结论

1. **本周相对本周计划**
   - 分析本周整体完成情况
   - 对比计划与实际的差异
   - 给出完成度的总体评价

2. **0313 以来阶段主线**
   - 总结从 0313 以来的主要工作主线
   - 识别工作重心的变化趋势
   - 评估阶段性目标的达成情况

3. **盯盘清单**
   - 列出需要重点关注的科室（偏离度高、风险大）
   - 指出需要跟进的关键事项
   - 提出管理建议或干预措施

---

### 4. 输入数据结构

Prompt 会为每个科室提供以下数据：

```markdown
### [科室名称]
**上周计划（下周工作计划）：**
[上周周报中的"下周工作计划"内容]

**本周实际完成：**
[本周周报中的"上周工作计划"任务列表]
[本周周报中的"本周工作内容"]

**本周下周计划：**
[本周周报中的"下周工作计划"]
```

**数据来源**：
- `上周计划`：通过 `getPrevWeekReport()` 获取上周周报的 `nextPlan` 字段
- `本周实际完成`：当前周报的 `content`（任务列表）和 `currentWork` 字段
- `本周下周计划`：当前周报的 `nextPlan` 字段

```javascript
      role: 'user',

  ],
  temperature: 0.3,  // 较低温度确保输出稳定和格式一致
  max_tokens: 4000   // 足够的 token 数支持多部门分析
}
```

## 使用场景

1. **周度管理会议**：为管理层提供全局视角的周报分析
2. **风险预警**：及时发现偏离度高的科室和延迟的关键任务
3. **资源调配**：根据各科室完成情况调整资源分配
4. **绩效评估**：作为科室绩效评估的参考依据
5. **趋势分析**：跟踪长期工作主线的推进情况

## 注意事项

1. **数据完整性**：如果某科室缺少上周数据，会显示"无上周数据"，AI 应据此调整分析策略
2. **格式严格性**：输出必须严格遵循 Markdown 格式，便于前端解析和渲染
3. **客观性**：分析应基于数据事实，避免主观臆断
4. **可操作性**：盯盘清单应给出具体的科室和事项，而非泛泛而谈
5. **时效性**：分析应聚焦当前周和近期趋势，避免过度追溯历史

## 技术实现

- **函数位置**：`src/components/weekly-report-v2/WeeklyReportV2.tsx` 的 `handleGlobalAnalysis`
- **数据获取**：`getReportsByWeek(selectedWeek)` 获取当前周所有部门周报
- **结果展示**：通过 Drawer 组件展示，支持 Markdown 渲染和表格高亮
- **状态管理**：`globalAnalysisLoading` 控制加载状态，`globalAnalysisResult` 存储分析结果
